03 — ProcessFrom blueprint to build

  1. 01

    Discovery

    Define the "how might we" and the real constraints of the brief.

  2. 02

    Wireframe

    Grayscale, mobile-first. If it doesn't work without color, color won't fix it.

  3. 03

    Semantics

    Header, nav, main, article, footer — the right landmark for the right job.

  4. 04

    Style

    CSS Grid for structure, Flexbox for components, a restrained 2025 palette.

  5. 05

    Logic

    Light, purposeful JavaScript for state and interactivity — nothing more.

  6. 06

    Audit

    Check layout shift, load speed, and accessibility before calling it done.
